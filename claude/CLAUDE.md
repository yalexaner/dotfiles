## Version Control

- use **jujutsu (jj)** as the primary vcs — use `jj` for commits, bookmarks, rebasing
- on windows (msys): bare `jj` and `git` work fine in the bash tool
- on windows (cmd.exe contexts like statusline, hooks): must use `jj.exe` and `git.exe`
- commit with the `/commit` skill, not manually

## Code Commenting Guidelines

- always write comments with lowercase letters
- for kdoc/javadoc, follow their respective guidelines for capitalization
